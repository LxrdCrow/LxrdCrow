## 🧠​ Area of Interests



### 🌐 **Networking & System Communication**

- Solid foundation in networking fundamentals (OSI vs. TCP/IP, packet/frame structure, encapsulation, core network components).
- Protocol understanding: IP (IPv4/IPv6), TCP, UDP — headers, flow control, error handling, and connection lifecycle.
- Practical exposure: traffic analysis with Wireshark, port scanning concepts, and network behavior observation.
- Focus area: low-level client–server communication, sockets, ports, and how applications interact with the network stack.
- Perspective: studying networking as a base layer for system design and cybersecurity.

---

### 🔐 **CyberSecurity (Current Focus)**

- Core principles: CIA Triad, threat surfaces, OWASP Top 10, and secure coding practices.
- Application security mindset: API protection, input validation, authentication/authorization flows, and minimizing attack surface.
- Hands-on exploration: hotspot configuration analysis, basic port scanning, traffic inspection, and vulnerability awareness.
- Approach: understanding how vulnerabilities arise from system design, network behavior, and implementation choices.
- Direction: moving toward deeper application security, protocol-level understanding, and defensive system design.

---

### 🔑 **Cryptography and Cryptanalysis**

- Understanding of symmetric vs. asymmetric encryption (AES, RSA, ECC), hashing (SHA family), and digital signatures.
- Role of cryptography in real systems: TLS/SSL, certificates, PKI, and secure key handling.
- Introductory cryptanalysis concepts: brute force, dictionary attacks, entropy, and secure randomness.
- Goal: strengthening the theoretical backbone required for application security and secure communications.
